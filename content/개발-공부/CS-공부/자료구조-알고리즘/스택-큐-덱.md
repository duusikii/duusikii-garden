# 스택 / 큐 / 덱

## 스택 (Stack)
- **LIFO** (Last In First Out)
- push / pop / peek — 모두 **O(1)**
- 활용: 함수 호출 스택, 괄호 검사, DFS, 뒤로가기

## 큐 (Queue)
- **FIFO** (First In First Out)
- enqueue / dequeue — **O(1)**
- 활용: BFS, 작업 대기열, 메시지 큐

## 덱 (Deque)
- 양쪽 끝 삽입/삭제 가능
- 슬라이딩 윈도우 문제에서 자주 사용

## ❓ 면접 질문
**Q. 스택 2개로 큐를 구현하세요.**
> inbox 스택에 push, dequeue 시 inbox → outbox로 옮겨 pop.

**Q. 우선순위 큐(Priority Queue)란?**
> 힙(Heap) 자료구조 기반. 삽입/삭제 O(log n), 최솟값/최댓값 O(1).
