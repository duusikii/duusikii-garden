# 트리 & 그래프

## 트리 (Tree)
- 계층적 구조, 사이클 없음
- 루트 → 부모 → 자식 관계

### 이진 탐색 트리 (BST)
- 왼쪽 < 루트 < 오른쪽
- 탐색/삽입/삭제 평균 **O(log n)**, 최악 **O(n)** (편향)
- 균형 유지: AVL 트리, Red-Black 트리

### 힙 (Heap)
- 완전 이진 트리
- 최소 힙: 부모 ≤ 자식
- 삽입/삭제 **O(log n)**, 최솟값 조회 **O(1)**

## 그래프 (Graph)
- 정점(Vertex) + 간선(Edge)
- 방향/무방향, 가중치/비가중치

### 탐색
| | BFS | DFS |
|-|-----|-----|
| 자료구조 | 큐 | 스택(재귀) |
| 최단경로 | ✅ (가중치 없을 때) | ❌ |
| 사이클 탐지 | ✅ | ✅ |

## ❓ 면접 질문
**Q. 해시맵의 충돌 해결 방법은?**
> Chaining (링크드리스트), Open Addressing (선형 탐사).

**Q. B-Tree는 왜 DB 인덱스에 쓰이나요?**
> 디스크 I/O 최소화. 노드 하나에 많은 키 저장 → 트리 높이 낮음.
