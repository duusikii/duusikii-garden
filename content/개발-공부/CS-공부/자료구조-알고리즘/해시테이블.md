# 해시테이블 (Hash Table)

## 개념
- Key → 해시함수 → 인덱스 → Value 저장
- 탐색/삽입/삭제 평균 **O(1)**

## 해시 충돌
- **Chaining**: 같은 인덱스에 링크드리스트로 연결
- **Open Addressing**: 다음 빈 슬롯 탐색 (선형/이중 탐사)

## Load Factor
- `저장된 항목 수 / 전체 버킷 수`
- 보통 0.75 초과 시 리사이징 (Java HashMap)
- 리사이징: 새 배열 생성 후 전체 rehashing → **O(n)**

## ❓ 면접 질문
**Q. HashMap은 thread-safe한가요?**
> ❌ 아님. ConcurrentHashMap 사용해야 안전.

**Q. equals()와 hashCode()를 같이 오버라이딩하는 이유?**
> HashMap은 hashCode로 버킷 찾고 equals로 같은 키 확인. 둘 다 일관성 있어야 함.
