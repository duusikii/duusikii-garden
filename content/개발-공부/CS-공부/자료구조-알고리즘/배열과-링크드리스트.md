# 배열 & 링크드리스트

## 배열 (Array)
- 연속된 메모리 공간에 저장
- 인덱스로 **O(1)** 랜덤 접근
- 삽입/삭제 **O(n)** (중간 삽입 시 밀기 필요)

## 링크드리스트 (LinkedList)
- 각 노드가 다음 노드의 포인터를 가짐
- 삽입/삭제 **O(1)** (노드 위치 알 때)
- 탐색 **O(n)** (처음부터 순회)

## ❓ 면접 질문
**Q. ArrayList vs LinkedList 언제 쓰나요?**
> 조회가 많으면 ArrayList, 삽입/삭제가 많으면 LinkedList.
> 단, Java LinkedList는 캐시 지역성 때문에 실제로는 ArrayList가 더 빠른 경우 많음.

**Q. 배열과 링크드리스트의 메모리 차이는?**
> 배열은 연속 메모리, 링크드리스트는 포인터 오버헤드 있음.

## 시간복잡도 정리
| 연산 | 배열 | 링크드리스트 |
|------|------|------------|
| 접근 | O(1) | O(n) |
| 탐색 | O(n) | O(n) |
| 삽입(끝) | O(1) | O(1) |
| 삽입(중간) | O(n) | O(1) |
| 삭제 | O(n) | O(1) |
