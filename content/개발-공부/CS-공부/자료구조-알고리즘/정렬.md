# 정렬 알고리즘

## 시간복잡도 비교

| 알고리즘 | 평균 | 최악 | 공간 | 안정 |
|---------|------|------|------|------|
| 버블 | O(n²) | O(n²) | O(1) | ✅ |
| 선택 | O(n²) | O(n²) | O(1) | ❌ |
| 삽입 | O(n²) | O(n²) | O(1) | ✅ |
| 합병(Merge) | O(n log n) | O(n log n) | O(n) | ✅ |
| 퀵(Quick) | O(n log n) | O(n²) | O(log n) | ❌ |
| 힙(Heap) | O(n log n) | O(n log n) | O(1) | ❌ |

## ❓ 면접 질문
**Q. 퀵정렬 최악이 O(n²)인 경우는?**
> 피벗이 항상 최솟/최댓값일 때 (이미 정렬된 배열).
> 랜덤 피벗 or 중간값 피벗으로 회피.

**Q. Java Arrays.sort()는 어떤 알고리즘?**
> 기본 타입: Dual-Pivot QuickSort / 객체 타입: TimSort (합병+삽입).

**Q. 안정 정렬이 중요한 경우는?**
> 이미 정렬된 키가 있을 때 순서 유지가 필요한 경우. 합병정렬, 삽입정렬이 안정.
