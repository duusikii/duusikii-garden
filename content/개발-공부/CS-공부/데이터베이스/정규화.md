# 정규화 (Normalization)

## 목적
- 데이터 중복 제거
- 이상(Anomaly) 방지: 삽입/삭제/갱신 이상

## 정규형
| 정규형 | 조건 |
|--------|------|
| **1NF** | 원자값 (반복 그룹 제거) |
| **2NF** | 부분 함수 종속 제거 |
| **3NF** | 이행 함수 종속 제거 |
| **BCNF** | 모든 결정자가 후보키 |

## 역정규화 (De-normalization)
- 성능을 위해 의도적으로 중복 허용
- 조회 성능 ↑ vs 데이터 정합성 관리 필요

## ❓ 면접 질문
**Q. 정규화를 무조건 해야 하나요?**
> 아니요. 조회가 많고 성능이 중요하면 역정규화가 나을 수 있음.
> 트레이드오프를 고려해야 함.
