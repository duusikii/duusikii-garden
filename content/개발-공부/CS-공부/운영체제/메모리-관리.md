# 메모리 관리

## 메모리 구조
```
[ 코드(Code) ]   → 실행할 명령어
[ 데이터(Data) ] → 전역변수, static
[ 힙(Heap) ]     → 동적 할당 (new, malloc) ↓ 아래로 증가
[ 스택(Stack) ]  → 지역변수, 함수 호출 ↑ 위로 증가
```

## 가상 메모리
- 실제 RAM보다 큰 메모리를 사용하는 것처럼 보이게 함
- 페이징: 메모리를 고정 크기 페이지로 나눔
- 페이지 폴트: 필요한 페이지가 RAM에 없을 때 디스크에서 로드

## ❓ 면접 질문
**Q. 스택 오버플로우란?**
> 재귀 호출이 너무 깊거나 지역변수가 너무 많아 스택 공간 초과.

**Q. 메모리 누수(Memory Leak)란?**
> 동적 할당한 메모리를 해제하지 않아 계속 쌓이는 현상.
> Java GC가 자동 관리하지만 참조가 남아있으면 수거 안 됨.

**Q. GC(Garbage Collection)란?**
> 더 이상 참조되지 않는 객체를 자동으로 메모리에서 해제.
> Stop-the-world: GC 동안 애플리케이션 일시 중지.
