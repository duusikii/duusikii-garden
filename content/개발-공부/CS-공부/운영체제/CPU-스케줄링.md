# CPU 스케줄링

## 주요 알고리즘
| 알고리즘 | 특징 |
|---------|------|
| FCFS | 먼저 온 순서대로 (Convoy Effect 문제) |
| SJF | 짧은 작업 먼저 (기아 가능) |
| Round Robin | 시간 할당량(Quantum)씩 번갈아 |
| Priority | 우선순위 높은 것 먼저 (기아 가능) |

## 핵심 용어
- **선점형**: CPU 실행 중 강제 빼앗기 가능
- **비선점형**: 실행 끝날 때까지 대기
- **기아(Starvation)**: 낮은 우선순위 프로세스가 계속 대기
- **에이징(Aging)**: 대기 시간 길어질수록 우선순위 높여서 기아 방지

## ❓ 면접 질문
**Q. I/O 바운드 vs CPU 바운드 프로세스란?**
> I/O 바운드: 입출력 대기 시간이 긴 프로세스 (DB 쿼리, 파일 읽기).
> CPU 바운드: 계산이 많은 프로세스 (영상 인코딩, 암호화).
