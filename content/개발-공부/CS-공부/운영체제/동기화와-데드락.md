# 동기화 & 데드락

## 동기화 도구
- **뮤텍스(Mutex)**: 1개 스레드만 접근. lock/unlock
- **세마포어(Semaphore)**: N개 스레드 동시 접근 허용
- **모니터(Monitor)**: Java synchronized 내부 구현

## 데드락 (Deadlock)
### 4가지 필요 조건 (모두 충족 시 발생)
1. **상호 배제**: 자원은 한 번에 하나만 사용
2. **점유 대기**: 자원 점유하면서 다른 자원 대기
3. **비선점**: 강제로 자원 빼앗을 수 없음
4. **순환 대기**: A→B→C→A 순환 의존

### 해결 방법
- **예방**: 4가지 조건 중 하나 제거
- **회피**: 은행원 알고리즘
- **탐지 & 복구**: 데드락 탐지 후 프로세스 종료

## ❓ 면접 질문
**Q. Livelock이란?**
> 데드락과 달리 스레드가 계속 실행되지만 진전이 없는 상태.

**Q. Race Condition이란?**
> 여러 스레드가 공유 자원에 동시 접근해 결과가 실행 순서에 따라 달라지는 현상.
