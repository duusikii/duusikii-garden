# 분산 시스템

## CAP 정리
- **C**onsistency: 모든 노드가 같은 데이터
- **A**vailability: 항상 응답 가능
- **P**artition Tolerance: 네트워크 분단에도 동작
- **P는 필수** → C와 A 중 하나 선택

## 수평 확장 vs 수직 확장
| | 수직 (Scale Up) | 수평 (Scale Out) |
|-|----------------|-----------------|
| 방법 | 서버 사양 높이기 | 서버 대수 늘리기 |
| 한계 | 물리적 한계 있음 | 거의 무한 확장 |
| 비용 | 점점 비쌈 | 상대적 저렴 |
| 복잡도 | 낮음 | 높음 (분산 처리) |

## 분산 락
- 여러 서버가 공유 자원에 동시 접근 제어
- Redis `SET NX EX` 활용
- [[Flash-Sale-설계]] 참고
