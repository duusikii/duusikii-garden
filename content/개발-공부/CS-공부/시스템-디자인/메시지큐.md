# 메시지 큐 (Message Queue)

## 목적
- 서비스 간 **비동기 통신**
- 트래픽 버퍼링, 서비스 디커플링

## Kafka vs RabbitMQ
| | Kafka | RabbitMQ |
|-|-------|----------|
| 방식 | Pull (Consumer가 가져감) | Push (브로커가 전달) |
| 저장 | 디스크 영구 저장 | 소비 후 삭제 |
| 처리량 | 매우 높음 (수백만/초) | 중간 |
| 적합 | 대용량 로그, 이벤트 스트림 | 작업 큐, RPC |

## 메시지 큐 사용 예시
- 주문 완료 → 이메일 발송 큐 → 이메일 서비스
- 결제 완료 → 재고 차감 → 배송 시작 (이벤트 체인)
