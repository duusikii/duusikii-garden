# 라이브 코딩 팁

## 라이브 코딩 ≠ 온라인 코테

면접관이 보고 있으니까 **사고 과정이 핵심!** 정답보다 과정이 중요하다.

---

## 진행 순서 (5단계)

### 1. 문제 이해 (1~2분)
```
"입력이 이렇고 출력이 이건가요?"
"엣지 케이스: 빈 배열, null, 중복은 어떻게 하나요?"
"음수가 포함될 수 있나요?"
```

### 2. 접근법 설명 (3~5분)
```
"브루트포스로 O(N²)인데, HashMap 쓰면 O(N)으로 줄일 수 있습니다"
→ 코드 치기 전에 먼저 말하기!
```

### 3. 코딩 (10~15분)
```
변수명 의미 있게
막히면 "여기서 고민되는 부분은..."이라고 말하기
완벽한 코드보다 동작하는 코드 먼저
```

### 4. 테스트 (3~5분)
```
직접 예시로 손으로 트레이싱
엣지 케이스 확인
```

### 5. 최적화 토론
```
"시간 O(N), 공간 O(N)입니다"
"공간을 줄이려면..."
```

## 주의사항

- **침묵하지 말 것** — 생각하는 과정을 말로 설명
- **완벽하지 않아도 됨** — 브루트포스부터 시작해서 최적화
- **엣지 케이스 먼저 확인** — null, 빈 배열, 단일 원소, 중복
- **시간/공간 복잡도 항상 언급**
